Antes da fase 3

Na última fase você vai usar três coisas novas. Guarde bem:

git stash — guarda suas mudanças por um tempo, para você trocar de ramo ou baixar algo sem perder o trabalho.

git reset --hard — apaga commits e mudanças. É perigoso: nunca use para desfazer o trabalho dos outros.

Trazer um arquivo de volta — para buscar um arquivo de um commit antigo: git checkout <commit> -- arquivo.
